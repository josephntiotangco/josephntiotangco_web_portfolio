# Joseph Nunag-Tiotangco Web Portfolio

Vue/Vite professional portfolio focused on work experience and selected projects.

## Local Preview

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Deploy to Vercel

From this folder:

```powershell
vercel --prod
```

Use the current directory as the project root.

Vercel settings:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## Public-Safety Note

This site intentionally excludes IDs, civil registry documents, clearances, TORs, and other sensitive documents.
